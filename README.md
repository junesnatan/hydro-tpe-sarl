> **L'Excellence de l'Ingénierie Hydraulique & l'Expertise BTP au Bénin**

---

## 🌊 À Propos du Projet

Ce site vitrine a été conçu pour **HYDRO TPE SARL**, entreprise et bureau d'études de référence basé en République du Bénin (siège à Cotonou, bases opérationnelles à Abomey-Calavi et Parakou).

Le design s'inspire des plus hauts standards internationaux de l'industrie du BTP et de l'ingénierie (inspiré des maquettes de prestige *Built Right Construction* et *Case Construction*), avec une identité visuelle corporate associant :
- **Bleu Nuit Profond & Acier Technique** (`#071322`, `#0a1b2f`, `#163250`) évoquant l'autorité, la solidité structurelle et la rigueur d'ingénierie.
- **Or Industriel & Ambre Sécurité** (`#f59e0b`, `#fbbf24`) pour les appels à l'action, les éléments de réassurance et les accents de chantier.
- **Cyan & Azur Hydraulique** (`#0284c7`, `#38bdf8`) symbolisant la pureté de l'eau, le pompage moderne et la transition écologique.

---

## 🏗️ Pôles d'Intervention & Contenus Spécifiques au Bénin

1. **Hydraulique Villageoise, Urbaine & Pastorale** :
   - Forages d'exploitation profonds (jusqu'à 250 m) en milieu sédimentaire (Littoral, Atlantique, Ouémé) et zone de socle cristallin (Collines, Borgou, Donga, Atacora).
   - Systèmes d'Adduction d'Eau Potable (AEP / SAEP multi-villages).
   - Châteaux d'eau en béton armé banché et réservoirs métalliques surélevés.
   - Stations de pompage 100% solaires photovoltaïques (Lorentz, Grundfos) au fil du soleil.

2. **Ingénierie-Conseil, Bureau d'Études & BTP** :
   - Maîtrise d'Œuvre (MOE) et Assistance à Maîtrise d'Ouvrage (AMO).
   - Études géotechniques, dimensionnement structural (BAEL 91 / Eurocodes).
   - Contrôle technique de chantier et surveillance de travaux.

3. **Assainissement & Drainage Pluvial** :
   - Caniveaux de drainage, dalots cadres, collecteurs d'eaux pluviales et lutte anti-inondations.

4. **Aménagements Hydro-Agricoles & VRD** :
   - Périmètres irrigués (goutte-à-goutte, aspersion), retenues collinaires et barrages agro-pastoraux.

## 🚀 Démarrage & Commandes

### Prérequis
- [Node.js](https://nodejs.org/) (version 18+)
- [npm](https://www.npmjs.com/)

### Installation
```bash
npm install
```

### Lancer le serveur de développement
```bash
npm run dev
```
Accédez au site à l'adresse : `http://localhost:5173/`

### Compiler pour la production
```bash
npm run build
```
Les fichiers optimisés et minifiés sont générés dans le dossier `/dist`.

### Prévisualiser le build de production
```bash
npm run preview
```
